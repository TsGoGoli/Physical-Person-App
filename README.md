
# 📘 ფიზიკური პირების ცნობარი API

ეს პროექტი წარმოადგენს RESTful API-ს ფიზიკური პირების მონაცემების სამართავად. სისტემაში შესაძლებელია პიროვნების დამატება, რედაქტირება, წაშლა, დაკავშირებული პირების მართვა, სურათის ატვირთვა, ძიება და რეპორტინგი.

## 🔧 ტექნოლოგიები და არქიტექტურა

* **.NET 8**
* **Entity Framework Core / Dapper**
* **SQL Server**
* **Repository Pattern & Unit of Work**
* **Global Exception Handling Middleware**
* **Request Validation Filter**

---

## 📦 ფიზიკური პირის მოდელი

| ველი             | აღწერა                                                                    |
| ---------------- | ------------------------------------------------------------------------- |
| `Id`             | უნიკალური იდენტიფიკატორი (auto-increment integer)                         |
| `FirstName`      | სავალდებულო, 2-50 სიმბოლო, მხოლოდ ქართული ან ლათინური ასოებით             |
| `LastName`       | სავალდებულო, 2-50 სიმბოლო, მხოლოდ ქართული ან ლათინური ასოებით             |
| `Gender`         | "კაცი" ან "ქალი"                                                          |
| `PersonalNumber` | სავალდებულო,正 11 ციფრი                                                    |
| `DateOfBirth`    | სავალდებულო, მინიმუმ 18 წლის ასაკი                                        |
| `CityId`         | ქალაქის იდენტიფიკატორი (Foreign Key)                                      |
| `PhoneNumbers`   | ტელეფონის ნომრების სია (`მობილური`, `ოფისის`, `სახლი`)                    |
| `PhotoPath`      | სურათის ფაილის relative მისამართი                                         |
| `RelatedPersons` | დაკავშირებული პირების სია (ტიპი: `კოლეგა`, `ნაცნობი`, `ნათესავი`, `სხვა`) |

---

## 🔁 API ფუნქციონალი

* ✅ ფიზიკური პირის დამატება
* ✏️ ფიზიკური პირის ძირითადი ინფორმაციის რედაქტირება
* 📤 სურათის ატვირთვა/განახლება (ფაილური სისტემაში შენახვით)
* 🔗 დაკავშირებული პირის დამატება/წაშლა
* ❌ ფიზიკური პირის წაშლა
* 🔍 ინფორმაციის მიღება იდენტიფიკატორით (სრული დეტალებით)
* 📄 ფიზიკური პირების სია:

  * სწრაფი ძებნა (სახელი, გვარი, პირადი ნომერი - `LIKE`)
  * დეტალური ძებნა (ყველა ველის მიხედვით)
  * გვერდების მიქცევა (pagination)
* 📊 რეპორტი: თითოეული ფიზიკური პირის დაკავშირებული პირების რაოდენობა კავშირის ტიპის მიხედვით

---

## ✅ ვალიდაცია და უსაფრთხოება

* ყველა მოთხოვნა გადის ვალიდაციის ფილტრს (`ActionFilter`)
* ლოკალიზებული შეცდომის მესიჯები (`Accept-Language` Header-ის მიხედვით)
* Global Exception Middleware ლოგირებისთვის და სტაბილური პასუხებისთვის
* მონაცემთა მთლიანობის კონტროლი ბაზის დონეზეც

---

## 📁 სურათების შენახვა

სურათები ინახება ფაილურ სისტემაში. API აბრუნებს შესაბამის ფაილის მისამართს (`relative path`), რომელიც შეიძლება გამოყენებული იქნას მომხმარებლის ინტერფეისში.
